# GLOSSARY.md — 용어집

이 워크스페이스의 문서·로그·실험 이름에 나오는 용어를 모았다.
**수치는 예시일 뿐 정본이 아니다** — 측정값의 정본은 [`RESULTS.md`](RESULTS.md),
선택 규칙은 [`PIPELINE_CATALOG.md`](PIPELINE_CATALOG.md).

---

## 1. 목표와 지표

| 용어 | 뜻 |
|---|---|
| **6D pose** | 물체의 3D 위치 + 3D 방향. 우리 표기는 `cam_T_obj` = **회전 R(3×3) + 평행이동 t(mm)** |
| **KPI** | 합격 기준 — **t ≤ 5mm 이고 R ≤ 3°**. "40/40" = 40프레임 전부 통과 |
| **R / t** | R = 회전(rotation), t = 평행이동(translation) |
| **ADD / ADD-S** | CAD 점들을 추정 pose 와 정답 pose 로 각각 옮겨 잰 평균 거리. **-S** 는 대칭을 허용(최근접 점끼리) |
| **MAE** | 평균 절대 오차 |
| **중앙값 / 평균 / p95 / max** | 이 프로젝트는 **평균만 보고 여러 번 틀렸다**. 지표는 항상 **중앙값·평균·최댓값을 함께** 본다 |
| **뒤집힘 (flip)** | 물체를 **90°/180° 돌아간 자세로** 추정한 실패. 대칭 물체에서 생기며 **평균에 묻히므로 건수를 따로 센다** |
| **오선택 (gross fail)** | 같은 종류의 **다른 개체**를 잡은 실패. 마스크는 깨끗해도 IoU 는 0 이다 → **건수를 따로 센다** |

## 2. 물체와 CAD

| 용어 | 뜻 |
|---|---|
| **FOUP** | 300mm 웨이퍼 25장을 담는 운반 용기. 이 프로젝트의 대상 물체 |
| **flange / `top_flange`** | FOUP **윗면의 손잡이판**(142×142mm). 로봇이 잡는 SEMI 표준 부위 |
| **`full`** | FOUP **전체** CAD. flange 만 떼면 회전 판별 정보가 사라진다 |
| **표준부 / 비표준부** | SEMI 가 규정하는 것은 flange 의 **테두리와 중심 홀뿐**이다. flange 중간부도, **body 도 제조사마다 다르다**. ⚠️ *"그러니 표준부만 쓰자"* 는 **측정으로 기각됐다** — 좁히면 방향 신호도 같이 줄어 오히려 약해진다(`RESULTS.md §20`) |
| **CAD-실물 불일치** | CAD 와 실제 물체의 형상 차이. **sim 이 원천적으로 못 보는 도메인 갭 축**(렌더와 CAD 가 같은 메쉬라 0). 배경·재질·센서와 나란한 독립 축으로 다룬다 |
| **하이브리드 CAD** | 다른 제조사 CAD 의 **body** + 우리 `top_flange`(바이트 동일)를 합친 검증용 객체(`assets/obj/foup_300_hybrid`). *"물체는 남의 것, CAD 는 우리 것"* 상황을 sim 에서 재현한다 |
| **rim 밴드** | `top_flange` 중 **테두리 띠만** 남긴 영역(XY 외곽선을 안쪽으로 W mm offset). 모델은 `cad.build_rim_obj`, 마스크는 `pose_fp --mask-band-mm`(실루엣을 반지름 `W·fx/Z` 원판으로 침식) — **둘을 같은 도형으로** 잘라야 한다. 측정 후 **기각**(`RESULTS.md §21`) |
| **원점(origin)** | pose 의 기준점. 우리 규약은 **flange 주 상면 중심**. `full` 과 부품이 **같은 원점**이어야 한다 |
| **회전 대칭 잔차** | 물체를 θ 돌려 원래 형상과 비교한 표면거리. **작을수록 그 각도로 착각하기 쉽다** |
| **템플릿** | CAD 를 여러 각도에서 렌더한 이미지 모음. ISM 이 이걸로 물체를 찾는다 |

## 3. 스테레오와 depth

| 용어 | 뜻 |
|---|---|
| **스테레오** | 좌우 두 카메라의 시차로 거리를 재는 방식 |
| **시차 (disparity)** | 같은 점이 좌우 영상에서 어긋난 픽셀 수. `깊이 = fx·B / 시차` |
| **σ_disp** | 시차 추정의 **픽셀 오차**. 이것이 깊이 오차로 증폭된다 |
| **`fx`** | 초점거리(픽셀). 클수록 확대해 본다 |
| **`B` / baseline** | 두 카메라 사이 거리 |
| **`fx·B`** | **깊이 분해능 지수** — 클수록 정확. D435 33,700 / ZED X 144,000 |
| **깊이 오차 모델** | `σ_Z = Z²/(fx·B) · σ_disp` ⚠️ **σ_disp 가 거리에 따라 줄어서 실측 지수는 0.8~1.0 이다**(2 아님) |
| **`Z/B` 비** | 같은 픽셀 오차가 **Z 를 X/Y 보다 몇 배 세게 때리는지**. 1m·B=50mm 에서 **20배** |
| **`valid.png`** | depth 가 유효한 픽셀 표시. depth 는 16-bit PNG, 값=mm, **0 = 무효** |

## 4. ★ depth 오차 주입 모드 — 실험 이름의 `iid` / `corrNN` / `scale` / `offset`

depth 에 **일부러 넣는 오차의 "모양"** 이다. 크기는 뒤에 붙는 숫자(mm).
예) `corr60_17` = **상관 길이 60px** 의 오차를 **평균 17mm** 크기로 주입.

| 이름 | 뜻 | 오차의 모양 | 현실의 원인 | 거리 지수 |
|---|---|---|---|---|
| **`iid`** | *independent and identically distributed* — **픽셀마다 독립** | 모래알처럼 자글자글 | 순수 센서 잡음 | p≈2 |
| **`corr20/60/200`** | **공간 상관** 잡음, 뒤 숫자 = 상관 길이(px) | 그 크기의 **얼룩**이 뭉텅이로 | 무늬 없는 면, 반복 패턴, 매칭 실패 | p≈2 |
| **`scale`** | `Z ×= (1+s)` | 멀수록 더 밀림 | baseline 캘리브레이션 오차 | p≈1 |
| **`offset`** | `Z += c` | 전체가 균일하게 밀림 | 원점·정렬 오차 | p≈0 |

### 왜 상관 길이가 중요한가

flange 는 근접에서 **약 142,000 픽셀**이다.

- **`iid`** → 평균 내면 **√142000 ≈ 378배** 상쇄 → 거의 무해
- **`corr60`** → 독립 얼룩이 ~40개뿐 → 상쇄가 **6배**로 줄어듦 → 치명적

**같은 17mm 인데 `iid` 면 근접 파이프라인 33/40, `corr60` 이면 3/40.**
게다가 FoundationPose 는 depth 에 `bilateral_filter(r=2)` 를 걸어 **자글자글한 잡음은 이미 지운다** —
덩어리진 오차만 통과한다. **iid 로 강건성을 평가하면 결론이 뒤집힌다.**

## 5. 분할(segmentation)

| 용어 | 뜻 |
|---|---|
| **마스크** | 이미지에서 물체가 차지한 픽셀 영역 |
| **IoU** | **교집합 ÷ 합집합**. 두 영역의 일치도(0~1). 1 = 완전 일치 |
| **precision / recall** | 예측 중 맞은 비율 / 정답 중 찾은 비율. **recall 이 낮으면 물체를 덜 잡은 것** |
| **proposal** | 분할 모델이 내놓은 **후보 영역**. 수십~수백 개 |
| **SAM** | Segment Anything Model. "물체 같은 영역"을 대량으로 뽑는다 |
| **ISM** | **Instance Segmentation Model** — SAM-6D 의 앞단. SAM 제안 + **CAD 템플릿 42장** 대조로 타깃을 고른다 |
| **SAM3** | 최신 분할 모델. 텍스트 또는 **exemplar(참조 이미지+박스)** 로 지정 |
| **exemplar** | **참조 이미지 + 박스**. "이렇게 생긴 걸 찾아라" 라는 지정 수단 |
| **`select score/center/exemplar`** | 후보가 여럿일 때 무엇을 타깃으로 고르나 — 점수 최대 / 화면 중앙 근접 / 참조와 IoU 최대 |
| **참조 선택 기준** | 후보 참조 중 **어느 것을 쓸지** 고르는 규칙. **면적 중앙값 상위 5장**이 최선이며 **GT 가 필요 없다** |
| **oracle 기준** | 정답(GT)을 알아야 계산되는 기준. 상한 참고용이며 **배포에는 못 쓴다** |

**GT-free** — 정답 라벨 없이 계산되는 지표/기준. **실환경에는 GT 가 없으므로 배포용은 전부 이래야 한다.**
IoU·R·t 오차는 GT-free 가 **아니다**.

**ISM 의 점수 구성** (`detector.py`):
```
최종점수 = (의미 + 외형 + 기하×가시율) / (1 + 1 + 가시율)
             RGB   RGB    ← depth 는 여기 하나뿐
```
→ **depth 는 3항 중 1항**이고 **마스크 자체는 RGB(SAM)가 만든다.**
그래서 depth 를 24mm 망가뜨려도 마스크가 **픽셀 단위로 동일**했다.

## 6. pose 추정 (FoundationPose)

| 용어 | 뜻 |
|---|---|
| **coarse** | 1차 추정. `register()` — 회전 후보 ~252개를 만들어 전부 정련한 뒤 **scorer 가 순위**를 매긴다 |
| **refine** | 2차 정련. 렌더한 CAD 와 관측을 비교해 pose 를 조금씩 고친다. ★ **관측이 옳다고 믿고 모델을 맞추는** 최적화라 — **모델이 틀리면(CAD 불일치) 켜고, 데이터가 틀리면(depth 오염) 끈다**. **평행이동 편향은 고치지만 실패한 회전은 못 고친다** |
| **`track_one()`** | pose 하나만 정련. **scorer 를 건너뛴다** → 초기값을 주면 이 경로가 되고, **대칭 후보를 아예 안 만들어 뒤집힘이 안 생긴다** |
| **scorer** | 여러 pose 후보의 순위를 매기는 신경망. **대칭 혼동이 일어나는 곳** |
| **crop / `input_resize`** | refiner·scorer 는 물체 주변을 잘라 **160×160 으로 리사이즈**해 본다 |
| **crop 정규화** | crop 크기 = **mesh 지름 × 1.2** → **거리와 무관**하게 같은 크기로 보인다. **가까이 가도 회전 판별력은 안 늘어난다** |
| **`symmetry_tfs`** | 대칭을 선언하는 인자. ⚠️ **후보 격자 중복제거에만** 쓰이며, 선언하면 등가 자세 중 **임의의 하나**를 반환한다 → 우리처럼 정확한 방향이 필요하면 **쓰면 안 된다** |

## 7. 파이프라인 이름 — `F?` + `G?`

| | 뜻 |
|---|---|
| **F** | **원거리(1단계)** 구성 — 어떻게 찾고 어느 것을 타깃으로 정하나 |
| **G** | **근접(2단계)** 처리 — 가까이 간 뒤 그 관측을 어떻게 쓰나 |

배포 파이프라인 하나 = `F?` + `G?`. 예) **`F1 + G9`**.

| ID | 내용 | 상태 |
|---|---|---|
| **F1** | ISM + 중앙 선택 | **현행 기준** |
| F2 | SAM3 exemplar | 유지(대조) |
| F5 | ISM + exemplar 지정 | **기각** — 오선택 증가 |
| **G0** | 근접에서 **재추정 안 함** — 원거리 결과를 좌표변환만 | **기준선 / 강건성 챔피언** |
| **G1** | 근접에서 **부품 CAD 로 처음부터** 재추정 | clean 최고, 오염에 취약 |
| G3 | 근접에서 `full` + 초기값 → 부품 refine | 열위 |
| G5 | **게이트** — G0 와 G1 의 회전이 τ 이상 어긋나면 G1 폐기 | G9 의 성분 |
| G7 | **R 은 G0, t 는 G1** 로 합침 | G9 의 성분 |
| **G9** | **G5 게이트 + G7 융합** | **단일 시점 최선** |
| **G10** | 여러 **시점**에서 n회 추정해 **융합**(+ 인라이어 합의) | 채택 |
| **G9+G10** | 회전=원거리 n개 융합, 인라이어 **과반**일 때만 근접 t 채택 | **★ 전체 최선** |
| G6 | 정지 **다중 프레임** 융합 | **기각** — 오차장이 반복해도 같다 |
| G11 | RGB 실루엣으로 회전 결정 | **기각** — 판별 마진 < 마스크 오차 |
| G8 | 3단계(원거리→중거리→근접) | **미측정** |

⚠️ **G6(정지 다중 *프레임*)과 G10(다중 *시점*)은 다른 것이다.** 같은 자리에서 여러 장 찍는 것은
오차가 그대로 반복돼 소용이 없고, **시점을 옮겨야** 오차가 탈상관돼 융합이 듣는다.

## 8. 융합과 로봇

| 용어 | 뜻 |
|---|---|
| **chordal 평균** | 여러 회전의 평균. 행렬을 평균 낸 뒤 SVD 로 회전행렬로 되돌린다 |
| **인라이어 (inlier)** | 서로 **합의하는** 추정들. 튀는 것을 버리고 이것만 융합 |
| **정족수 (quorum)** | 인라이어가 **과반**일 때만 그 결과를 채택하는 안전장치. 없으면 소수의 나쁜 값을 믿게 된다 |
| **정족수 미달 후퇴** | 인라이어가 과반이 안 되면 근접 결과를 버리고 원거리로 돌아가는 것. **GT 없이 얻는 신뢰도 신호** |
| **hand-eye** | **카메라 ↔ 로봇 손** 사이의 변환. 캘리브레이션 오차 + 순기구학 오차의 합 |
| **hand-eye 증폭** | 회전 오차 δθ 는 평행이동 오차 `δt ≈ d·δθ` 를 만든다(d = 물체까지 거리). **1m 에서 0.3° = 5mm** |
| **좌표변환(transport)** | 한 시점의 pose 를 다른 시점 기준으로 옮기는 것. **hand-eye 가 필요하다** |

## 카메라·운용 (2026-08-12 추가)

| 용어 | 뜻 |
|---|---|
| **rectified / raw** | 스테레오 정류본 / 원본. **우리는 rectified 만 소비한다** — 정류 후 `disto` 가 0 이라 우리 핀홀 모델과 동형이다. ZED X raw 는 `k1 0.543` 의 강한 배럴 |
| **`Min-Z`** | RealSense 데이터시트의 최소 depth 거리. **D4 ASIC 의 시차 탐색 한계(126)를 거리로 환산한 값**이고 원시 L/R 을 직접 쓰는 우리에게는 **적용되지 않는다** (`CAMERAS.md §1.5`) |
| **과초점거리 `H`** | `H = f²/(N·c)`. 이 거리에 초점을 맞추면 `H/2`~∞ 가 선명하다. ZED X 2.2mm 은 H≈489mm → **0.24m 부터 선명** |
| **물체 투영 픽셀 수** | 정합 정밀도를 지배하는 변수. **«화소 수» 가 아니다** — 광각이면 해상도를 올려도 물체가 차지하는 픽셀은 줄 수 있다(교훈 #70). `flange 등가 지름 = 2√(마스크면적/π)` 로 잰다 |
| **정합기 자체 오차 바닥** | **GT 를 초기값으로 주고 게이트 없이** 돌렸을 때의 결과(횡단 정리 #48). 이 값이 입력보다 나쁘면 **어떤 파라미터로도 이득이 안 난다** — 튜닝 전에 먼저 잰다(#71) |
